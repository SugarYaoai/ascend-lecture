C API 与 C++ API 的代码组织差异

AscendC 架构演进对比
架构维度 C API C++ API 工程价值
GM 地址、类型与范围 __gm__ float* 配合手写指针偏移 GlobalTensor<float> 绑定地址、元素类型和当前 Block 长度 将分散在指针、偏移量和长度常量中的约束集中封装，消除类型不匹配与越界风险
长度参数的计量单位 搬运写字节数 BLOCK_LENGTH * sizeof(float)；计算写元素数 DataCopy、Add 统一传入 blockLength 个元素 由 Tensor 类型自动推导元素宽度，无需手动换算 sizeof(float)，避免单位混用 Bug
UB 资源与流水线演进 __ubuf__ 静态数组直接占用 UB LocalMemAllocator + LocalTensor 描述 UB 局部资源 集中管理 UB 生命周期；多 Tile / 多 Buffer 场景可平滑过渡至 TPipe、TQue 队列调度
底层物理执行模型未变
GM → UB → Vector → UB → GM

GlobalTensor 与 LocalTensor 绑定数据范围，DataCopy 负责搬运，PipeBarrier 负责 AI Core 内阶段依赖同步——C++ API 提升的是资源、单位与生命周期的表达力，而非替代硬件执行步骤。
