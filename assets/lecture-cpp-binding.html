1.4.1 从 C API 到 C++ API 的重构三步法

1.4.1.1 编译时模板参数：template <uint32_t blockLength>

1 / 2
LocalMemAllocator::Alloc<float, blockLength>() 需在编译期获知局部张量长度以规划 UB 固定空间，因此 blockLength 升级为 add_custom 的 C++ 模板参数（Host 侧通过 add_custom<BLOCK_LENGTH> 实例化）。
第三节：C API — 静态宏/常量定义 
constexpr uint32_t NUM_BLOCKS = 16;
constexpr uint32_t BLOCK_LENGTH = 10752;
constexpr int64_t TOTAL_LENGTH =
    NUM_BLOCKS * BLOCK_LENGTH;
本节：C++ API — 编译期模板化内核 
template <uint32_t blockLength>
__vector__ __global__ void add_custom(
    GM_ADDR x, GM_ADDR y, GM_ADDR z)
{
    // blockLength 用于 UB 分配。
}
编译期常量传播：模板参数 blockLength 直接参与片上 UB 静态容量计算，零运行时分支开销。
GM_ADDR 为无类型字节地址；先经 reinterpret_cast<__gm__ float*> 强转使 + offset 按 4 B 步长偏移，再通过 SetGlobalBuffer 绑定当前 Block 的 GM 起始地址与元素长度（仅建立视图映射，不触发数据搬运）。
第三节：C API — 裸指针偏移 
const uint32_t offset =
    block_idx * BLOCK_LENGTH;
__gm__ float* xGm =
    reinterpret_cast<__gm__ float*>(x) + offset;
__gm__ float* yGm =
    reinterpret_cast<__gm__ float*>(y) + offset;
__gm__ float* zGm =
    reinterpret_cast<__gm__ float*>(z) + offset;
本节：C++ API — 强类型张量视图绑定 
AscendC::GlobalTensor<float> xGm, yGm, zGm;
const uint32_t offset = block_idx * blockLength;
xGm.SetGlobalBuffer(
    reinterpret_cast<__gm__ float*>(x) + offset, blockLength);
yGm.SetGlobalBuffer(
    reinterpret_cast<__gm__ float*>(y) + offset, blockLength);
zGm.SetGlobalBuffer(
    reinterpret_cast<__gm__ float*>(z) + offset, blockLength);
强类型元数据封装：GlobalTensor 同时携带 float 元素类型与 blockLength 边界信息，消除后续搬运时的字节/元素单位混淆。
