C API 裸指针痛点

工程痛点
1 单位易混淆

DMA 用字节（10752 * sizeof(float)），计算用个数（10752），漏写不报错却越界。

2 流水线难维护

__ubuf__ 手工算偏移，多 Buffer 复用与切分极易出错。

C++ API 强类型破局

架构演进
1 张量带类型长度

GlobalTensor<float> / LocalTensor<float> 自动约束数据类型与长度。

2 结构化片上管理

LocalMemAllocator 统筹 UB，为升级 TPipe / TQue 队列流水线打底。

核心本质

底层物理搬运规则不变，只是在硬件之上套一层强类型外衣，在编译期拦截低级错误。
